dev

Keep the app running while you work; it rebuilds when you save.

app/views/layouts/application.eiy 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title><%= yield_content "title" %> · Blog</title>
  <link rel="icon" href="/icon.svg" type="image/svg+xml">
  <link rel="stylesheet" href="/assets/app.css">
</head>
<body>
  <header class="topbar">
    <a class="brand" href="/">Blog</a>
    <nav><a href="/posts">Posts</a><!-- kurt:nav --></nav>
  </header>
  <main class="container">
    <% if notice = flash?("notice") %><p class="flash notice"><%= notice %></p><% end %>
    <% if alert = flash?("alert") %><p class="flash alert"><%= alert %></p><% end %>
    <%= content %>
  </main>
  <%= raw(live_reload_tag) %>
</body>
</html>

What it printed

kurt dev
[development] blog is ready to lead at http://localhost:3000
  • It watches app/, config/, db/schema.json and iyi.mod.
  • It builds beside the running server. When the build succeeds, the new server replaces the old one and the page reloads, through live_reload_tag at the bottom of the layout.
  • A change that does not build shows the error at your line, and the last good server keeps answering.
  • public/ is served from disk. It needs no restart.

Try it on your machine

Keep it running while you edit.

sh 
$ kurt dev -p 3000

Kurt

Kurt is Turkish for wolf. It is an MVC web framework for iyi: models read their columns from the database, views are compiled with the app, and kurt build ships everything as one file.
