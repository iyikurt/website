controllers

Controllers handle requests: they load data and render a view.

app/controllers/posts_controller.iyi 
class PostsController < ApplicationController
  before_action :set_post, only: [:show, :edit, :update, :destroy]

  # GET /posts
  def index
    @posts = Post.order_desc(:id).paginate(params[:page]?, per: 25).all!
    render "posts/index"
  end

  # GET /posts/:id
  def show
    render "posts/show"
  end

  # GET /posts/new
  def new
    render "posts/new"
  end

  # POST /posts
  def create
    @post = Post.new(post_params)
    if @post.save!
      redirect_to path_to(@post), notice: "Post was created."
    else
      render "posts/new", status: 422
    end
  end

  # GET /posts/:id/edit
  def edit
    render "posts/edit"
  end

  # PATCH /posts/:id
  def update
    if @post.update(post_params)!
      redirect_to path_to(@post), notice: "Post was updated."
    else
      render "posts/edit", status: 422
    end
  end

  # DELETE /posts/:id
  def destroy
    @post.destroy!
    redirect_to "/posts", notice: "Post was deleted."
  end

  # The record the action works on; a missing one is a 404 before the
  # action runs.
  private def set_post
    @post = Post.find(params[:id])!
  end

  # The fields the form may set: strong parameters.
  private def post_params : Hash(String, String)
    params.require(:post).permit(:title, :body, :published)
  end
end
  • Each public method is an action. A route reaches it by name.
  • Filters run first. before_action, with only: or except:. One that answers Unauthorized, Forbidden, NotFound or DBError stops the action.
  • Params are text. params[:id] is "" when missing, params[:q]? is nil. permit is the only way from a form to a model, and converts to the field types.
  • @post and @posts need no declaration. A variable named after a model holds that model, its plural an array of it, so neither is ever nil.
