scaffold

Generate a model, a migration, a controller, views, routes and a test with one command.

sh 
kurt generate scaffold Post title:string body:text published:bool
kurt db:migrate

What it printed

kurt g scaffold · kurt db:migrate
    create  app/models/post.iyi
    create  db/migrations/20261126212518_create_posts.sql
    create  app/controllers/posts_controller.iyi
    create  app/views/posts/index.eiy
    create  app/views/posts/show.eiy
    create  app/views/posts/new.eiy
    create  app/views/posts/edit.eiy
    create  app/views/posts/_form.eiy
    update  config/routes.iyi
    update  app/views/layouts/application.eiy
    create  test/posts_test.iyi
   migrate  20261126212518_create_posts
      dump  db/schema.json
    update  app/models/post.iyi

A field is name:type. The types are string, text, int, float, bool, time and references; user:references gives a user_id column and belongs_to user. g is short for generate.

CommandWrites
kurt g scaffoldmodel, migration, controller, five views, routes, test
kurt g modelmodel and migration
kurt g controllercontroller, views, routes
kurt g migrationan empty migration
kurt g authenticationusers, sign-in, sign-up

Try it on your machine

Then open localhost:3000/posts and add one.

sh 
$ kurt g scaffold Post title:string body:text published:bool
$ kurt db:migrate
$ kurt dev

Kurt

Kurt is Turkish for wolf. It is an MVC web framework for iyi: models read their columns from the database, views are compiled with the app, and kurt build ships everything as one file.
