What it printed

.kurt/build/
app/controllers.iyi
app/fixtures.iyi
app/models.iyi
app/routes.iyi
blog.iyi
iyi.mod
posts_test.iyi

What you write has no module header and no imports. kurt dev, kurt test and kurt build turn it into iyi modules under .kurt/build/, which you never edit:

  • Every model goes into one module, with a property for each column. iyi forbids import cycles, and in one module a User and its Posts may still name each other.
  • Every controller goes into another, ApplicationController first.
  • config/routes.iyi becomes the router's body.

A build error still points at your file and line. A file that needs another module writes its own import at the top.

Try it on your machine

Build once, then look at what the build wrote.

sh 
$ kurt build
$ ls .kurt/build

Kurt

Kurt is Turkish for wolf. It is an MVC web framework for iyi: models read their columns from the database, views are compiled with the app, and kurt build ships everything as one file.
