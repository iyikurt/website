views

Write pages as HTML with iyi code inside.

app/views/posts/index.eiy 
<% content_for "title" do %>Posts<% end -%>
<div class="page-header">
  <h1>Posts</h1>
  <%= link_to "New post", "/posts/new", class: "button" %>
</div>

<% if @posts.empty? %>
<p class="empty">No posts yet.</p>
<% else %>
<table class="table">
  <thead>
    <tr>
      <th>Title</th>
      <th>Published</th>
      <th></th>
    </tr>
  </thead>
  <tbody>
  <% @posts.each do |post| %>
    <tr>
      <td><a href="<%= path_to(post) %>"><%= post.title %></a></td>
      <td><%= post.published %></td>
      <td class="row-actions">
        <%= link_to "Edit", path_to(post) + "/edit" %>
        <%= button_to "Delete", path_to(post), method: :delete, class: "link danger", confirm: "Delete this post?" %>
      </td>
    </tr>
  <% end %>
  </tbody>
</table>
<% end %>

render "posts/index" draws this file inside layouts/application.eiy. A typo here is a build error, not a 500. The view reads the controller's instance variables as they are.

  • Escaping. <%= %> escapes; raw(x) does not.
  • Partials. A name ending in .eiy: render "_form.eiy", post: @post, or once per item with collection:.
  • Layouts. layout: "admin" picks another; layout: false draws none.

Kurt

Kurt is Turkish for wolf. It is an MVC web framework for iyi: models read their columns from the database, views are compiled with the app, and kurt build ships everything as one file.
