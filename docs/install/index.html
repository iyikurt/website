install

Install Kurt from source, next to iyi.

sh 
git clone https://github.com/iyikurt/kurt.git ~/src/kurt
cd ~/src/kurt
make install                 # links bin/kurt into ~/.local/bin
export PATH="$HOME/.local/bin:$PATH"

What it printed

kurt version
kurt 0.1.0
  • iyi 0.21.0 or later. Tried with 0.22.0.
  • A C compiler. cc links the program and the SQLite bindings.
  • SQLite. macOS already has it. PostgreSQL is optional, through DATABASE_URL.

Kurt is an iyi package, github.com/iyikurt/kurt, versioned by git tags. kurt new writes its own version into the application's iyi.mod, and iyi fetches the package on the first build. KURT_PATH=~/src/kurt kurt new app builds against your checkout instead.

Try it on your machine

It prints its version when it is on your PATH.

sh 
$ kurt version

Kurt

Kurt is Turkish for wolf. It is an MVC web framework for iyi: models read their columns from the database, views are compiled with the app, and kurt build ships everything as one file.
