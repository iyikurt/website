tests

Test your app through its routes, on a fresh database.

test/posts_test.iyi 
# `kurt test` runs this against db/test.sqlite3, freshly migrated, through
# the routes and without a socket.
Post.delete_all.as(Int64)
app = RouteHandler.new(routes)

res = dispatch(app, "GET", "/posts").response
assert res.status_code == 200

# a blank title is refused, and the form comes back
res = dispatch(app, form_request("POST", "/posts", "post%5Btitle%5D=")).response
assert res.status_code == 422
assert Post.count.as(Int64) == 0

# a valid form creates one and redirects to it
res = dispatch(app, form_request("POST", "/posts", "post%5Btitle%5D=Example&post%5Bbody%5D=Example&post%5Bpublished%5D=1")).response
assert res.status_code == 303
post = Post.last?.as(Post)
assert res.headers["Location"]? == "/posts/" + post.id.to_s
assert dispatch(app, "GET", "/posts/" + post.id.to_s).response.status_code == 200

# a missing one is 404
assert dispatch(app, "GET", "/posts/999999").response.status_code == 404

# deleted through the form-friendly route
res = dispatch(app, form_request("POST", "/posts/" + post.id.to_s + "/delete", "")).response
assert res.status_code == 303
assert Post.count.as(Int64) == 0

What it printed

kurt test
1 passed, 0 failed

kurt test migrates a fresh test database and runs every test/*_test.iyi, each starting from the rows in test/fixtures/*.yml. A label's id is the same on every run, so fixtures name each other:

# test/fixtures/posts.yml
welcome:
  title: Welcome
  user: ada          # the id of ada in users.yml

A test reads a row as posts(:welcome), and sign_in_as(users(:ada)) signs the next requests in.

Try it on your machine

Run the scaffold's test.

sh 
$ kurt test

Kurt

Kurt is Turkish for wolf. It is an MVC web framework for iyi: models read their columns from the database, views are compiled with the app, and kurt build ships everything as one file.
