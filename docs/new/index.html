new

Create a new application with one command.

sh 
kurt new blog --css none
cd blog
kurt dev

What it printed

kurt new blog --css none
    create  iyi.mod
    create  config/application.iyi
    create  config/routes.iyi
    create  app/models/.keep
    create  app/controllers/application_controller.iyi
    create  app/controllers/home_controller.iyi
    create  app/views/layouts/application.eiy
    create  app/views/home/index.eiy
    create  public/assets/app.css
    create  public/icon.svg
    create  db/migrations/.keep
    create  test/fixtures/.keep
    create  db/seeds.iyi
    create  .gitignore
    create  AGENTS.md
    create  CLAUDE.md

Created blog. Next:
  cd blog
  kurt generate scaffold Post title:string body:text published:bool
  kurt db:migrate
  kurt dev

Sixteen files: the configuration, a home page and its layout, a stylesheet, folders for the database and the tests, and the two files a coding agent reads first. kurt dev serves it at localhost:3000.

  • With Tailwind CSS and daisyUI by default. The standalone Tailwind CLI is fetched once into ~/.cache/kurt/ and checked against the release's checksums. No Node.
  • Or with plain CSS. --css none leaves both out, as here.

Try it on your machine

Then open localhost:3000.

sh 
$ kurt new blog
$ cd blog
$ kurt dev

Kurt

Kurt is Turkish for wolf. It is an MVC web framework for iyi: models read their columns from the database, views are compiled with the app, and kurt build ships everything as one file.
